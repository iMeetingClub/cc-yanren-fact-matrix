     ### 3.6 动态比例：持续营销如何改变分成
     
     **关键前提：每月结算，收入归零。**
     
     收入每月结算一次——当月产生的销售收入，当月按 NT 占比分完，结算后余额归零。下个月的收入完全来自下个月的新销售。
     
     这意味着：如果没有人持续推广，销量会逐月衰减。营销不能是"做完教程顺手发一下"，而是一个需要持续投入的工作。**持续投入需要持续的 NT 预算来激励。**
     
     **机制设计（修订版）**：
     
     1. **两阶段 NT 预算，提前申请**：
        - 第一阶段（制作期，第1月）：**5,500 NT 上限**，用于课程制作任务
        - 第二阶段（营销期，第2-4月）：**每月 1,000 NT × 3 个月 = 3,000 NT**，用于持续营销推广任务
        - **两次预算一次性申请**，营销 NT 在收入到账之前就已到位，可以直接驱动推广
     
     2. **营销任务示例**：发小红书推广笔记（50-80 NT/篇）、制作宣传短视频（200-300 NT/条）、社群运营（100 NT/周）、评论区互动维护（50 NT/周）、联系 KOL 合作（100-200 NT/次）等。每项任务附带 NT 奖励，**任何人（无论是否参与制作）都可以认领**
     
     3. **NT 池每月增长**：每当有人完成一项营销任务并获得 NT，该课程的**总 NT 池就相应增长**，所有人的分成比例自动重新计算
     
     4. **每月结算流程**：
        - 月初：新一批营销任务在 NT 任务平台上发布
        - 月中：成员认领并完成营销任务，获得 NT → 总 NT 池增长
        - 月末：当月销售收入到账 → 按当月最新的累计 NT 占比分配 → **余额归零**
        - 下月：重复上述流程
     
     **核心公式（完整版）**：
     
     > 个人当月分成 = 当月课程销售收入 ×（个人累计 NT / 课程总 NT 池累计值）
     >
     > 其中：课程总 NT 池 = 制作阶段 NT + 上线后所有营销任务 NT 累计
     
     **比例浮动示例**（假设营销带动的销量增长）：
     
     | 月份 | 事件 | 当月新增营销NT | 总NT池累计 | 月收入 | 砚仁(制作1,200NT) | 小白(营销累计) | 文峰(营销累计) |
     | ---- | ---- | ------------- | --------- | ------ | ----------------- | -------------- | -------------- |
     | 第1月 | 上线首发，自然销售 | 0 | 4,500 | ¥2,000 | 26.67% → ¥533 | 0% → ¥0 | 0% → ¥0 |
     | 第2月 | 小白开始推广 | +400 | 4,900 | ¥3,500 | 24.49% → ¥857 | 8.16% → ¥286 | 0% → ¥0 |
     | 第3月 | 文峰加入推广 | +700 | 5,600 | ¥4,500 | 21.43% → ¥964 | 12.50% → ¥563 | 5.36% → ¥241 |
     | 第4月 | 多人持续营销 | +900 | 6,500 | ¥5,000 | 18.46% → ¥923 | 累计 ¥1,450 | 累计 ¥643 |
     
     > **注意**：每月收入到账、分配后归零。上表中每人每月的分成是该月实际到手的金额，不累计到下月。
     
     **关键观察**：
     
     - 砚仁的**百分比在下降**（26.67% → 18.46%），但**绝对月收入在涨**（¥533 → ¥923），因为营销把总收入做大了
     - 小白从零开始，两个月累计收入 ¥1,450——这直接来自她的营销 NT 占比
     - **不做营销的人，比例自然稀释；做营销的人，比例持续增长**——激励方向清晰
     
     ### 3.7 为什么是 3 个月营销期
     
     一条付费课程从上线到触及售卖极限，通常需要 2-3 个月的持续推广：
     
     - **第1月**：首波社群转发 + 朋友圈自然转化（种子用户）
     - **第2月**：平台自然流量 + 口碑传播开始发酵
     - **第3月**：可能获得平台推荐 / 工笔画圈内传播 / 小爆款
     
     3 个月后，根据实际销售数据，DAO 再决定：
     - 销售稳定 → 可减少营销 NT 预算，进入低维护状态
     - 仍在增长 → 追加营销 NT 预算，继续推动
     - 销售疲软 → 复盘原因，调整策略或停止追加
     
     ### 3.8 对制作团队的保障
     
     动态比例可能会让制作团队成员担心份额被稀释。保障措施：
     
     1. **制作 NT 永不失效**：你在制作阶段获得的 NT 永久计入该课程的总 NT 池，不会被剥夺
     2. **营销 NT 总量可控**：DAO 批准的营销 NT 预算是固定的（3,000 NT），不会无限稀释。制作 NT（4,500）始终占大头
     3. **总收入增长才是核心**：营销的目标是把蛋糕做大。18.46% × ¥5,000 = ¥923 > 26.67% × ¥2,000 = ¥533
     4. **制作团队也可以做营销**：砚仁、视频剪辑等同样可以认领营销任务，一边推广自己的课程一边维持份额
